# TREAT Team RealScout Lead-Capture Site

A standalone static site that runs entirely on the RealScout widgets already on the TREAT account. Built to take paid traffic (Meta, Google) and turn it into RealScout registrations, which sync to Follow Up Boss.

## Pages

- `index.html` — homepage in the style of a branded agent site: hero with the Advanced Search widget, home value section with the Home Value widget, areas served, sell band, team.
- `search.html` — full-page home search. Same Advanced Search widget, widened to 1120px so listings have room to browse (the card embed on the homepage keeps the 500px width from the RealScout embed code).
- `home-value.html` — seller landing page for paid ads: minimal nav, Home Value widget twice, how it works, seller proof points. This is the page to point seller campaigns at.

## Search landing pages (16)

Generated by `generate_search_pages.py`. Each page targets one search phrase, has its own title, meta description, and local copy, embeds the Advanced Search widget for on-site capture, and carries a button to the branded RealScout map search (`https://treatrealty.realscout.com/homesearch/map?for_sale=1&for_rent=0`), the same portal buyers already use. Two doors, both end in RealScout.

Cities: Charleston, Hanahan, Summerville, Mount Pleasant, Daniel Island, Point Hope, North Charleston, Goose Creek, Moncks Corner, Johns Island.
Property types: condos (Charleston and Mount Pleasant), townhomes, new construction, waterfront, luxury.

To add a page (for example, condos in Summerville, or homes under a price point): add one entry to PAGES in the generator with its copy, re-run `python3 generate_search_pages.py`, and it writes the page and refreshes `sitemap.xml`. The homepage has a Popular Searches index linking the set, and every search page cross-links four related searches.

Note on ranking: these pages give paid ads a matched landing page today (ad-to-page match is what lowers cost per click). Organic ranking is a slower build that depends on the domain they live on and links pointing at them; the sitemap is included for when the site goes live.

## Widgets

Both widgets use agent-encoded-id `QWdlbnQtMjcyNDIy` (decodes to Agent-272422) and the exact embed code from RealScout:

- Head, once per page: `<script src="https://em.realscout.com/widgets/realscout-web-components.umd.js" type="module"></script>` plus the widget style blocks.
- Body: `<realscout-advanced-search>` and `<realscout-home-value>` components.

Widget styling matches the embed code RealScout generated (button color rgb(35, 93, 137)). The rest of the site uses the TREAT palette (navy #013046, teal #1f9ebc, gold #fdb515, orange #f5831f) and Montserrat.

## How leads flow

1. A visitor registers or requests a valuation inside a widget.
2. The lead lands in RealScout under the team account and gets listing alerts / home value alerts.
3. RealScout activity syncs into Follow Up Boss, where the lead system takes over.

Pool watch: the RealScout pool is 5,500 contacts team-shared and was at roughly 5,410 used in late October 2026. Paid traffic that registers eats pool slots. Each additional batch of 500 auto-nurture contacts is +$9.99/month, so check the pool before scaling spend.

## Tracking paid traffic

Use a separate URL per campaign so spend ties to registrations:

- Seller ads: `home-value.html?utm_source=facebook&utm_medium=cpc&utm_campaign=sellers-hanahan`
- Buyer ads: `search.html?utm_source=google&utm_medium=cpc&utm_campaign=buyers-summerville`

RealScout reports registrations inside its own dashboard; FUB shows the follow-on activity. Keep one campaign per area so cost per registration is visible by market.

## Going live (pick one)

1. **Subdomain of findhomessc.com (recommended):** create `search.findhomessc.com` (or similar) in DNS and point it at a free static host (Netlify or Cloudflare Pages). Upload this folder as-is. Keeps the brand domain and costs nothing.
2. **New domain:** register a short local domain (for example a Charleston homes or home value name) and host the same folder the same way. Better for ads that should not look like an agent site.
3. **WordPress page on findhomessc.com:** possible, but the SparkSite/WordPress setup has rejected full-page HTML before, and a separate host keeps paid landing pages fast and isolated. Not recommended.

No build step. Any static host serves the folder as-is.
